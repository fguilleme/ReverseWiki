# Reverse Wiki — kit App Store

Ce dossier contient les textes et captures prêts pour App Store Connect.

## Localisations

| Dossier | Langue App Store |
| --- | --- |
| `fr-FR` | Français (France) |
| `en-US` | Anglais (États-Unis) |
| `de-DE` | Allemand |
| `es-ES` | Espagnol (Espagne) |
| `pt-PT` | Portugais (Portugal) |
| `ru` | Russe |
| `ja` | Japonais |
| `zh-Hans` | Chinois simplifié |
| `ar-SA` | Arabe |

Chaque dossier contient :

- cinq captures PNG iPhone 6,5 pouces au format `1284 × 2778 px` dans
  `screenshots/` ;
- cinq captures PNG iPad 12,9/13 pouces au format `2064 × 2752 px` dans
  `screenshots-ipad/`.

Les captures originales iPhone 6,9 pouces sont conservées séparément dans
`screenshots-6.9-originals/`.

## Ordre conseillé des captures

1. Écran d’accueil et promesse du produit
2. Choix du fournisseur et du modèle multimodal
3. Identification visuelle et fait vérifié
4. Carte, sources et options de partage
5. Aide et fonctionnement de l’app

## Éléments restant à fournir dans App Store Connect

- URL d’assistance
- URL de politique de confidentialité
- coordonnées de contact pour l’équipe de validation
- déclaration de confidentialité des données
- catégorie principale recommandée : `Voyages`
- catégorie secondaire recommandée : `Éducation`

La photo de phare utilisée dans les captures est une création originale générée
pour Reverse Wiki. Le mode de démonstration qui l’affiche n’est activé que par
l’argument de lancement `-appStoreScreenshotMode` lors de la production des
captures.
