# Español (España)

## Nombre
Reverse Wiki

## Subtítulo
La historia oculta de lugares

## Texto promocional
Fotografía un lugar, descubre la historia detrás de la imagen y compruébala mediante fuentes y un mapa.

## Descripción
¿Y si cada lugar escondiera otra historia?

Reverse Wiki identifica un monumento, una calle, un edificio o un paisaje a partir de tu foto. Después contrasta el relato turístico habitual con un hecho histórico menos conocido y fuentes que puedes consultar.

• Haz una foto o impórtala  
• Usa el GPS si resulta útil: siempre es opcional  
• Elige tu proveedor y modelo de inteligencia artificial  
• Consulta el hecho verificado, el relato común, las fuentes y el mapa  
• Recupera o elimina descubrimientos desde el historial  
• Comparte una postal o un PDF completo con foto, texto y mapa

Reverse Wiki es compatible con Gemini, Claude, GPT, Kimi, OpenRouter y servicios compatibles con OpenAI. Solo muestra modelos capaces de comprender texto e imágenes.

Prueba el acceso compartido de Gemini, añade tu propia clave gratuita de Gemini para un uso más fiable o elige un modelo de pago. Las claves API se guardan en el Llavero del dispositivo.

Las respuestas de una IA pueden contener errores. Revisa siempre las fuentes citadas antes de compartir una afirmación.
